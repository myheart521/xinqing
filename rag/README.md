# 心理知识库材料与处理流程

这里补回参赛源码中的 DOCX 知识库处理脚本。脚本读取段落、清理空白、切分文本，使用 `shibing624/text2vec-base-chinese` 计算向量，再导出 `chunks.csv`、`embeddings.npy` 与包含文本和向量的 `data.json`。原电脑绝对路径已改为命令行参数。

## 使用

在仓库根目录创建独立 Python 环境并执行：

```bash
python -m venv .venv-rag
# Linux/macOS: source .venv-rag/bin/activate
# PowerShell: .venv-rag/Scripts/Activate.ps1
pip install -r rag/requirements.txt
python rag/process_counselor_data.py --input /path/to/authorized-knowledge.docx --output rag/processed_data
```

首次执行需要下载嵌入模型。输入应为你有权使用、已经检查过个人信息的知识文档。输出包含原文，属于同一份资料的派生文件，不能因为变成向量就当作匿名数据公开。

## 本次核对结果

原 `Dataset_RAG` 含教师心得 DOCX、160 条已处理知识片段及对应向量。其中出现明确的转载标记、具名培训经历和第一人称咨询经验叙述，材料也未给出统一开放许可证。因此本仓库保留可复用处理代码，并将知识组织方法整理在下方；不把这份混合来源原文或其向量直接重新分发。这里不是历史知识库的完整内容副本。

## 可复用的知识组织方法

| 主题 | 建议整理的内容 | 检索结果的使用方式 |
| --- | --- | --- |
| 倾听与共情 | 如何确认对方表达、使用开放式提问、避免过早下结论 | 为对话提供表达方式参考 |
| 学习与生活压力 | 作息、任务拆分、情绪记录与求助资源 | 给出可选择的小步骤，结合用户实际情况 |
| 人际与家庭沟通 | 边界、需求表达、冲突中断与恢复沟通 | 提供沟通选项，不替用户作重要决定 |
| 咨询流程 | 预约、知情说明、保密范围和转介机制 | 引导至实际存在的校园服务 |
| 高风险情境 | 人工介入渠道、紧急联系流程与服务边界 | 采用机构审核的流程，交由专业人员复核 |

这些是本次整理的结构说明，不是诊疗手册，也不包含真实咨询个案。新增条目建议记录来源、许可、审校日期、适用范围和撤回方式，便于后续更新。

## 与应用的关系

后端 `Embedding/` 目录保留 LangChain4j 检索、嵌入存储和聊天记忆集成。此脚本输出的是离线实验格式，不能将 `data.json` 直接视为后端已自动导入的数据库；接入时需要匹配后端使用的嵌入模型、维度和存储格式。

历史切分器以字符数切分，默认上限 512、长句窗口重叠 50；不等同于 tokenizer 的 token 数。脚本沿用原处理算法，文中短于 50 字符的片段会被过滤。用于新的知识库前，应检查实际片段边界与检索效果。
