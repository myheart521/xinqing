# 公开内容与材料整理清单

本次 `v1.1.0` 对照开发目录、完整参赛源码、历史归档、用户手册、研究报告、PPT 和服务器模型文件重新整理。原始工作目录保持不变，公开仓库中使用的是经过检查的副本。

## 源码选择

| 内容 | 采用版本 | 为什么这样选 |
| --- | --- | --- |
| Java 后端 | 包含 2026 年 5 月更新的开发版本 | 比初次公开的 2025 年版本多出 WebSocket 握手鉴权、学生工具意图处理、心理预警模型配置与对应测试；与归档中的文件内容交叉核对 |
| 教师管理端 | 较新的开发版本 | 保留教师、预约、聊天、预警与工具页面 |
| UniApp 学生端 | 完整参赛基础 + 较新功能页面 | 较新开发目录本身缺少公共模块，不能单独视作完整工程；保留完整依赖结构，并补回数字人、展厅与预约等页面 |
| HarmonyOS 学生端 | 完整参赛工程 | 保留资源与配置结构，移除原签名和身份配置 |
| 数字人 | 独立 Web 工程及客户端集成 | 保留实现与授权入口，按第三方许可安装所需 SDK |
| 知识库处理 | 原 DOCX 分块与向量脚本 | 改为本地参数配置；原混合来源知识文本不作为公开授权语料 |
| 数据库 | 62 张表的结构 | 供建立空实例，不携带真实业务记录 |

上一次被整体替换的普通图标、插画和小游戏贴图已逐项复核并恢复。真实账户头像、历史用户上传内容、私人云存储内容不能仅凭页面引用就获得公开授权；这部分继续使用本地示例或用户自行配置的资源。

恢复清单包含 25 个较新后端源码／测试文件、8 个下载与 SSE 示例文件、5 个学生端页面／组件和 223 个原始图片资源，逐文件路径、动作和当前 SHA-256 见 [SOURCE_RECOVERY.json](SOURCE_RECOVERY.json)。此外补回了字体、加载动画、4 条页面路由和被忽略规则误排除的管理端源文件；它们与配置、集成修正均记录在本版 Git 变更中。

## 未上传内容的具体范围

- 真实学生、教师及咨询业务数据，包括账号、手机号、测评结果、私聊、日记、预约详情和数据库数据行。
- 原服务器连接、Redis/数据库密码、模型 API Key、OSS 凭据、邮件凭据、签名证书及个人路径。
- 含身份信息的申报表、原始获奖证书、合作协议、私人聊天导出与未经整理的训练混合语料。
- `node_modules`、编译产物、模型优化器状态、缓存、重复归档和冗余演示视频。
- 没有逐曲开放授权的具名商业歌曲整曲；播放功能、示例资源和配置说明保留。

模型包保留推理所需参数与许可，清理私人路径和训练运行环境信息。公开模型的类型、上游要求、数据来源判断和未验证部分都在模型卡中说明。
