# 项目说明

## 使用场景

项目围绕校园心理支持服务组织学生端和教师端。学生浏览知识内容、参与交流、记录情绪、进行测评或发起预约；教师端提供内容管理、学生服务和分析相关界面。AI 模块辅助组织对话、检索和信息处理，不代替咨询师判断。

## 技术结构

后端分为 `xinqing-common`、`xinqing-pojo`、`xinqing-service`，分别承载公共组件、数据对象与业务服务。主要技术包括 Spring Boot、MyBatis-Plus、Sa-Token、MySQL 和 Redis；部分功能还涉及 RabbitMQ、对象存储、邮件及模型 API。

教师端采用 Vue 3、TypeScript、Vite、Element Plus 和 Pinia。学生端使用 UniApp；另保留鸿蒙端源码。SSE 和 WebSocket 服务流式输出与实时交流。数字人界面作为独立目录保留，厂商 SDK 和签名授权需自行集成。

AI 相关代码涉及 Spring AI、LangChain4j、模型接口适配、嵌入检索、MCP 工具和 Ollama。代码中存在多个实验与比赛阶段的集成，不代表每项服务都经过本次端到端验证。语音、数字人、地图和 PPT 等功能还依赖外部供应商服务。

历年材料使用心晴、EmoChat、织心和倾心等名称，模型及终端方案也曾变化。旧版 GLM 方案、后续 Qwen 方案和当前公开包的部署条件应分别理解。没有原始评测依据的治愈率、满意度、用户规模和性能提升描述未转写成已验证成果。
