## 尚未验证或需要自行完成

- 本次没有连接真实 MySQL、Redis、RabbitMQ 和云服务完成整个应用的端到端验收；空库的权限、菜单与账号需要自行初始化。
- UniApp / HarmonyOS 需要对应 IDE、SDK、应用标识和签名；静态资源与路由核对不等同于手机或鸿蒙设备实机验收。
- 数字人、语音、地图、对象存储、PPT 等外部集成需要自己的授权与配置。历史比赛录像不是当前机器的运行验收记录。
- 下载的模型可以独立推理；要成为业务后端使用的本地模型服务，仍需匹配接口并配置服务地址。

默认配置中的示例地址和空凭据用于部署说明；它们不提供共享在线服务。
